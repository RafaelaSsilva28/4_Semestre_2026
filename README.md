## 💻 Sobre o repositório

Este repositório reúne os materiais desenvolvidos durante o **4º semestre de 2026** do curso de Desenvolvimento de Sistemas.

Aqui ficam organizadas atividades práticas, exercícios, testes e projetos realizados ao longo das aulas, permitindo acompanhar a evolução dos conhecimentos e registrar cada etapa do aprendizado.

Mais do que armazenar códigos, este espaço representa a evolução na programação, a experimentação de novas ideias e o desenvolvimento de habilidades na área da tecnologia.
